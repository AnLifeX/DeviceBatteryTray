# VGN V98Pro V2 键盘（2.4G 接收器）电量协议

> 来源：ATK V HUB 驱动（Electron）`dist/index-*.js` 中的 `EvisionApi` / `DevicePowerInfo`，并已在本机实测验证（2026-11-23）。

## 设备识别
| 项 | 值 |
|---|---|
| 接收器 VID:PID | `320F:5088`（USB 上报名 `VGN V98pro V2 2.4G Dongle`） |
| 有线直连 VID:PID | `320F:5055`（V HUB 中同系列有线 PID，未实测） |
| 通讯接口 | UsagePage `0xFF1C`，Usage `0x92`（`MI_01&COL04`） |
| 报告长度 | 输入 64 / 输出 64 字节（含 Report ID） |

V HUB 中同一控制器 `EvisionApi` 覆盖了大量 VGN / VXE / ATK 键盘（S99、VXE75、N75 PRO、V87、KAFKA 等），PID `0x5088` 是这些 2.4G 接收器的共用 PID，协议应通用。

## 查询电量
向上述接口写输出报告（共 64 字节，不足补 0）：

```
04 LL HH 1A 00 00 ...
│  └──┘ └─ 命令字 power_info = 0x1A
│   └─── 请求序号（小端 16 位，任意非 0，回包原样带回，用于匹配）
└─────── Report ID = 4
```

回包（从同一接口读取输入报告）：

```
04 LL HH 1A 00 00 00 00 PP CC ...
                        │  └─ 充电标志：0 = 未充电，非 0 = 充电中
                        └──── 电量百分比（>100 时按 100 处理）
```

实测：`04 01 00 1A 00 00 00 00 49 00 ...` → 电量 73%，未充电。

## 键盘离线 / 休眠
键盘休眠或关机时，接收器会代为回复，命令字位置是 `FF`：

```
04 LL HH FF 00 00 ...
```

应视为「设备离线」，不要当作 0% 处理。键盘被按键唤醒后即可正常查询。

## 备注
- V HUB 界面会把电量四舍五入到 5 的倍数（73 → 75），我们显示原始值。
- 不需要先发 `start(0x01)` 握手，直接发 `0x1A` 即可。
- 读取时应过滤请求序号，接收器同一接口上可能还有其它异步上报。
